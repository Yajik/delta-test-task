# Тестовое задание для DELTA

Тестовое задание на позицию Frontend-разработчика.

Простой дашборд с таблицей ключевых метрик выручки и оплат. По клику на строку раскрывается линейный график тренда за неделю

## Технологии

- **Vite** — сборка и dev-сервер  
- **React** + **TypeScript** — основной стек  
- **Recharts** — отрисовка простого линейного графика (минималистичный, declarative API)  

Данные захардкожены в mocks (таблица + графики для каждой метрики).

## Запуск локально

```bash
# Установка зависимостей
npm install

# Запуск в разработке
npm run dev
# → http://localhost:5173

# Сборка для продакшена
npm run build
```

ДемоРазвёрнуто на Vercel (автоматический деплой с помощью GitHub):
[https://delta-test-task-one.vercel.app](https://delta-test-task-one.vercel.app/)

Структура проекта (кратко)

```
src/
├── components/
│   ├── Chart/          ← компонент графика (Recharts)
│   └── Table/          ← основная таблица
├── mocks/              ← hardcoded данные таблицы и графиков
└── App.tsx             ← корень с заголовком и Table
```
